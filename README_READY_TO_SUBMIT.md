
### Для запуска бота (локально)

```bash
# Установка
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Запуск
cd Task3 && python3 build_index.py    # Если индекс не готов (~15 min)
cd ../Task4 && python3 rag_api.py     # Запуск REST API

# Откройте: http://localhost:8000/docs
```

### Через Docker

```bash
docker-compose up --build
# API на http://localhost:8000
```

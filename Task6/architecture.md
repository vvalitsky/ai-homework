## Ключевые компоненты

### 1. DocumentChunker
- Разбивает документы на логические чанки (2000 символов)
- Старается завершать чанки на границах предложений
- Добавляет метаданные (source, title, chunk_id)

### 2. EmbeddingGenerator
- Использует модель `all-MiniLM-L6-v2`
- Генерирует 384-мерные векторы
- Кеширует модель для быстрого переиспользования

### 3. IndexUpdater
- Добавляет новые векторы в FAISS индекс
- Обновляет `chunks.json` с метаданными
- Сохраняет `index_info.json` с информацией об индексе
- Обновляет `history.json` с хешами файлов

### 4. Logger
- Основной лог: `logs/update_YYYYMMDD.log`
- Записывает все операции с временными метками
- Содержит подробную статистику обновления

## Установка и использование

### Ручной запуск:
```bash
cd Task6
bash run.sh
# Выбрать опцию 1 (Запустить обновление)
```

### Установка автоматического запуска (cron):
```bash
cd Task6
crontab crontab_config.txt
crontab -l  # Проверить установку
```

### Проверка логов:
```bash
cd Task6
bash run.sh
# Выбрать опцию 2 (Просмотреть последний лог)
# или опцию 4 (Статистика обновлений)
```

## Обработка ошибок

- Все исключения логируются в файл лога
- При ошибке чтения файла - пропускается документ, процесс продолжается
- При ошибке генерирования эмбеддингов - сообщение об ошибке и выход
- Сохраняется последнее удачное состояние индекса

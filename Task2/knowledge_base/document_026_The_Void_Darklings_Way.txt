# The Void Darklings Way

The Void Darklings are practitioners of the The Void Path, opposed to the Void Sentinels's philosophy.
        The core Void Darklings belief is that power and dominion are the highest goods. Their abilities include
        lightning generation, enhanced strength, and The Void Path influence. The Void Darklings Code states: 'Peace
        is a lie, there is only passion.' Each Void Darklings seeks to dominate others and gain supremacy. The
        Rule of Two limited Void Darklings to a Sage Conductor and an Apprentice to prevent their mutual destruction. The
        Void Darklings's hunger for power ultimately led to their downfall.
